# 高频类目候选词库

本文件提供扩展搜索的候选词，不提供事实认定。仅在用户描述、图片证据或商品参数支持时，把候选词写进主搜索式；否则放入“可尝试分支”或“待确认”。

## 通用采购与供货

| 买家说法 | 可尝试的供应链词 | 使用条件或提醒 |
|---|---|---|
| 批发、拿货 | 厂家直供、自有工厂、自营生产、自产自销 | 都可能是营销标签，不能据此确认工厂身份 |
| 便宜、清仓 | 库存、尾货、积压货、清仓、外贸余单 | 核对品相、尺码颜色、数量稳定性和补货能力 |
| 定做、印 logo | 贴牌、OEM、来图定制、来样定制 | ODM 是供应商参与设计，不等于简单印 logo |
| 做新外形 | 开模、模具开发、结构打样 | 询问模具费、归属、寿命和起订量 |
| 先买一个看看 | 拿样、样品、打样、色卡 | “打样”不一定等于拿现货样品 |
| 少量快速补货 | 小单快反、现货混批 | 核实最小起订量和交期 |
| 大批量 | 大货、批量订单、整单 | 询问阶梯价、产能和大货周期 |
| 出口款 | 跨境专供、外贸单、RTS 现货 | 不代表大牌同厂、授权或更高质量 |

## 服装与瑜伽裤

按“纤维成分 → 面料结构/后整理 → 版型结构 → 成衣品类 → 供货方式”拆解。

### 候选词

- 纤维：锦纶/尼龙、氨纶、涤纶、莱卡（莱卡是品牌纤维称呼，勿泛化为所有氨纶）
- 面料与性能：锦氨、高弹、四面弹、双面布、罗纹、裸感、速干、吸湿排汗
- 工艺/后整理：双面磨毛、无缝针织、一片式、热贴合
- 结构：高腰、提臀线、无尴尬线、七分/九分、裆部三角档
- 供货：成衣现货、面料现货、小单快反、库存尾货、OEM/ODM

### 转换示例

输入只有“高腰瑜伽裤”时：

- 安全主搜索：`高腰 女士 瑜伽裤`
- 材质分支：`锦氨 高腰 瑜伽裤`、`涤氨 高腰 运动打底裤`
- 工艺分支：`无缝针织 高腰 健身裤`、`双面磨毛 裸感 瑜伽裤`
- 库存分支：`高腰 瑜伽裤 库存尾货`
- 不得直接断言：260g/280g、锦纶比例、双面磨毛或无缝结构。

## 塑料收纳与周转盒

按“树脂/基材 → 成型工艺 → 结构 → 尺寸 → 用途 → 库存方式”拆解。

### 候选词

- 材质：PP、PS、PET、ABS、亚克力/PMMA
- 工艺：注塑、一体成型、吸塑（必须结合产品形态确认）
- 结构：分格、抽屉式、翻盖、卡扣、密封、带盖、可堆叠
- 工业叫法：整理盒、储物盒、周转盒、零件盒、物料盒、包装盒
- 供货：现货、库存、尾货、定制颜色、开模、OEM

### 转换示例

输入只有“内衣收纳盒”时：

- 安全主搜索：`分格 内衣 收纳盒`
- 材质分支：`PP 注塑 分格整理盒`、`ABS 抽屉式 收纳盒`
- 库存分支：`塑料 内衣整理盒 库存尾货`
- 找厂分支：`塑料收纳盒 注塑加工厂`
- 不得直接断言：材质、35×25cm、加厚或外贸尾货。

“食品级 PP”必须要求相应合规材料及检测证明，不能仅凭标题确认。

## 手机壳与注塑配件

按“材料 → 软硬形态 → 表面/结构工艺 → 适配机型 → 功能 → 供货方式”拆解。

### 候选词

- 材料：PC 硬壳、TPU 软胶、PC+TPU 复合、液态硅胶（需核实具体材料）
- 工艺/形态：注塑、素材壳、精孔、磨砂、喷油、IMD/IML、双色注塑
- 结构：全包、半包、气囊防摔、镜头全包、内置磁圈
- 供货：现货素材壳、库存尾货、来图定制、开模、OEM/ODM

### 转换示例

输入只有“防摔手机壳”时：

- 安全主搜索：`全包 气囊 防摔 手机壳`
- 材质分支：`TPU 软胶 全包 防摔壳`、`PC TPU 复合 防摔保护壳`
- 找厂分支：`手机保护壳 注塑加工 OEM`
- 询问机型后再加精确型号；不要凭空加入 6.1/6.7 寸。

输入“磁吸手机壳”时，“磁吸”可能是内置磁圈或材料本身支持磁吸，需核对磁铁数量、磁力参数、定位结构和兼容机型。

## 不能当作工厂证明的词

以下词既可能出现在工厂标题，也可能被贸易商使用：源头工厂、自产自销、厂家直供、外贸原单、注塑车间、自有厂房、ODM、尾货清仓。

推荐把它们用于扩大或缩小搜索结果，不用于最终认定。进一步核验：

- 主营类目是否集中，是否大量跨行业铺货
- 是否展示可对应产品的设备、车间和工序
- 是否能回答材料牌号、工艺限制、日产能和不良率
- 样品与大货的材料、结构和外观是否一致
- 定制 MOQ、模具、打样与量产周期是否符合生产逻辑
- 企业档案、经营年限、验厂信息和开票主体是否一致

# 1688 找货、产业带与供应商核验手册

## 四路找货法

### 1. 产业带候选搜索

公式：`产业带地名 + 核心品类 + 可选工艺/供货词`

产业带词用于扩大召回，不是真工厂证明。产业分工和企业分布会变化；回答时标注“常见候选，建议在 1688 当前结果中验证”。

| 品类 | 可尝试的产业带词 |
|---|---|
| 袜子 | 诸暨 |
| 保温杯、五金制品 | 永康 |
| 毛织、毛衣 | 大朗 |
| 针织服装、卫衣 | 即墨、中山（需结合具体品类核验） |
| 羽绒服 | 九江（注意存在多个同名地区，搜索时补省份） |
| 女包 | 狮岭 |
| 箱包、皮具 | 白沟 |
| 童装 | 织里 |
| 内衣 | 潮汕及其细分产业区，需继续确认具体城市/镇 |
| 假发 | 许昌 |
| 灯具 | 中山古镇 |
| 卫浴、陶瓷 | 潮州 |
| 窗帘、纺织面料 | 绍兴柯桥 |
| 小商品、饰品 | 义乌 |

不要为了凑产业带给每个商品强配地名。若不确定，省略地名并建议用户用平台产业带页面或当前商家分布验证。

### 2. 行业词搜索

按 `原料/面料 + 工艺 + 结构 + 品类` 生成。先输出不带营销标签的核心式，再给材质和工艺分支。

### 3. 去溢价标签与替代场景

先移除不决定生产的标签：网红、ins、轻奢、氛围感、专用、爆款。再寻找基础品类、工业名、商用名或上游部件名。

可用探索映射：

| 零售/场景词 | 可尝试的替代检索方向 | 必须核对 |
|---|---|---|
| 化妆品收纳盒 | 分格工具箱、美术工具箱、零件盒 | 材质、格口、清洁要求 |
| 桌面小垃圾桶 | 小型塑料桶、翻盖杂物桶 | 材质、异味、盖体结构 |
| 午睡毯、盖毯 | 航空毯、旅行毯、库存毛毯 | 克重、尺寸、瑕疵率、清洁状况 |
| 宠物碗 | 不锈钢小盆、食盆 | 食品接触材料、边缘处理、防滑结构 |
| 浴室置物架 | 商超陈列架、金属壁挂架 | 防锈、承重、安装方式；不默认与香烟架等价 |
| 露营折叠椅 | 折叠凳、钓鱼凳 | 承重、稳定性、座高和面料 |
| 金属床头柜 | 钢制矮柜、办公文件柜 | 尺寸、噪声、边角、家居安全性 |

这些只是“检索邻域”，不是同款或同品质保证。涉及食品接触、儿童、承重、电器、消防等安全场景时，不能仅因外观相似就推荐替用。

### 4. 以图搜款后再拆词

1. 使用无水印、主体清晰、背景简单的商品图进行平台以图搜款。
2. 从结果标题收集重复出现的品类、材质、工艺和结构词。
3. 不直接按第一条结果下单；用提取出的 2–4 个核心词重新文字搜索。
4. 对比至少三类结果：现货商家、库存/尾货商家、加工定制商家。
5. 先拿样核对材料、尺寸、做工与功能，再决定大货。

图片只能支持可观察特征，不能证明内部材料、授权、产地或工厂身份。

## 搜索标签：正向线索与风险线索

### 可作为生产能力线索

注塑、织造、开模、打样、大货、车间、生产线、自有厂房、实地验厂、超级工厂、RTS 现货、跨境专供。

这些标签只能用于筛选候选。贸易商也可能使用同样的标题或拥有合作工厂。

### 可能偏向分销的线索

一件代发、分销、微商供货、淘宝货源、网红爆款、全品类爆款货源。

不要一票否决：部分工厂同时提供代发，部分贸易商也可能适合小批量采购。根据采购目标判断。

## 真工厂核验清单

不要用单一信号下结论。综合核验：

1. **企业主体**：营业执照经营范围、注册地址、开票主体与收款主体是否一致。经营范围含生产/加工只是线索，不是现场生产证明。
2. **产品线**：主营是否集中，材料与工艺是否具有共同生产逻辑；跨品类并不自动等于贸易商。
3. **生产证据**：车间、设备、模具、工序、员工操作和产品能否相互对应，而非只有通用宣传片。
4. **专业问答**：能否说明材料牌号/成分、工艺限制、打样周期、日产能、良率和 MOQ。销售需要向技术人员确认也不自动等于中间商。
5. **样品与大货**：确认封样方式、色差/尺寸公差、验货标准、瑕疵处理和大货一致性。
6. **平台与第三方资料**：验厂报告、实力商家/超级工厂等可以提高可信度，但仍需看有效期、核验范围和主体名称。

## 沟通话术

### 个人或小批量拿样

```text
你好，我想采购【品类】，先拿【数量】个样品确认材质、尺寸和做工。如果合适，后续预计按【补货频率/数量范围】补货。请问现货样品价、MOQ、阶梯价和发货时间分别是多少？样品与后续大货是否同材质同工艺？
```

不要虚构“长期大单”来套价格。真实说明测试计划更利于获取可兑现的报价。

### 内容电商/直播测试

```text
你好，我们计划测试【品类】，首批预计【真实数量】，达到【真实条件】后考虑补货。请提供小批量价格、库存数量、补货周期、阶梯价、退换/瑕疵处理方式，以及是否支持中性包装或合规贴牌。
```

## 风险清单

- **尾货不等于完美品**：询问瑕疵类型、比例、是否可挑款、颜色尺码完整性和补货能力。
- **平替不等于同款**：结构相似不代表材料、性能、尺寸和寿命相同。
- **产业带不等于好货**：同一地区既有工厂也有贸易商，不只看地名。
- **极低价可能是引流 SKU**：下单前确认对应规格的实际库存、含税/包装/运费价格。
- **工厂 MOQ 可能更高**：个人小量采购时，贸易商或混批商可能总成本更低。
- **知识产权与平台规则**：不搜索、采购或传播仿牌、高仿及无授权品牌货源。

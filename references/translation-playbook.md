# 1688 拆词与输出手册

## 品类拆词框架

优先按下列顺序组织搜索式，按需省略：

`核心品类 + 材质 + 工艺 + 结构/款式 + 规格 + 用途/人群 + 供货方式`

不要把每一项都塞进一个搜索式。分别生成：

1. 宽搜：`核心品类 + 关键材质/结构`
2. 精搜：`核心品类 + 材质 + 工艺/规格`
3. 找厂：`核心品类 + 加工定制/源头厂家/OEM`
4. 找上游：`部件/坯料/面料/包材 + 关键属性`
5. 产业带：`候选地名 + 核心品类 + 工艺/厂家`
6. 去标签：`基础工业/商用品类 + 材质/结构`

## 挖源头厂的核心公式

把普通商品名改写为工厂生产和库存管理使用的组合词。优先生成以下三条路径：

1. **生产路径**：`面料名/原料名 + 工艺 + 品类`
   - 适合服装、家纺、箱包、包装、塑料和五金等能明确原料与工艺的商品。
   - 示例结构：`锦纶 裸感 双面磨毛 瑜伽裤`，而不是只搜“瑜伽裤”。
2. **库存路径**：`材质 + 尺寸/规格 + 尾货/库存/清仓`
   - 适合寻找低价现货、断码、外贸余单和工厂库存。
   - “尾货”可能存在颜色、尺码、数量不稳定或轻微瑕疵，必须核实品相和可持续补货能力。
3. **订单来源路径**：`外贸单/外贸尾单/原单余货 + 库存 + 工厂/厂家`
   - 适合寻找出口订单剩余库存，但“外贸单”“原单”只是卖家描述，不能当作品质或授权证明。
   - 涉及品牌标识时，核实授权，避免采购侵权货。

同一个商品至少给出一条普通找货式和两条工厂式，让用户能比较结果与价格。不要断言搜索结果一定是源头厂。

## 两种检索模式

### 找商品

目标是快速确认正确类目和市场叫法。使用：

`核心品类 + 关键材质/结构`

### 挖货源

目标是绕过纯零售标题，进入生产、库存或定制语境。依次尝试：

- 原料/面料 → 工艺 → 成品品类
- 材质 → 精确规格 → 尾货/库存
- 外贸单/库存 → 地区产业带 → 工厂/厂家
- 成品 → 半成品/部件/坯料 → 加工工艺

“厂家”“源头厂家”本身也可能是营销词。判断供应商时继续核验主营类目集中度、生产设备/车间、加工定制能力、MOQ、样品一致性、经营年限和验厂信息。

## 日常词到供应链维度

| 买家常说 | 需要追查的行业维度 |
|---|---|
| 软、舒服、亲肤 | 纤维成分、织法、克重、磨毛/水洗、填充、硬度 |
| 厚实、有分量 | 克重、厚度、密度、层数、基材 |
| 亮晶晶、闪 | 电镀、烫金、珠光、亮片、金葱、镭射、覆膜 |
| 看起来像木头 | 实木树种、竹木、密度板、刨花板、木纹贴皮/转印 |
| 金属感 | 不锈钢/铝合金/锌合金/铁、拉丝、喷涂、电镀 |
| 不容易坏 | 基材、壁厚、承重、连接结构、耐磨/耐折/耐腐蚀指标 |
| 防水 | 防泼水、防水涂层、防水等级、压胶、密封结构；不可混为一谈 |
| 环保、无毒 | 具体材料、执行标准、检测报告和适用场景，不直接当成事实 |
| 同款、平替 | 外形结构、关键材质、工艺和尺寸；避免只搜品牌名 |
| 定制 logo | 丝印、移印、热转印、烫印、激光雕刻、刺绣、织唛等，按材质确认 |

这些是拆解方向，不是固定一对一翻译。必须结合商品类别判断。

## 常用交易词

- **现货 / 一件代发 / 混批**：适合小批量试销，但分别确认库存、代发费用和混批门槛。
- **拿样 / 样品 / 样品费**：确认样品是否为大货同材质同工艺，以及下单后能否退样品费。
- **MOQ / 起订量 / 起订价**：区分现货起订量与定制起订量。
- **阶梯价**：按数量档位报价；确认是否含税、包装与运费。
- **来图定制 / 来样定制**：分别以图纸或实物样品为依据。
- **贴牌 / OEM**：通常指按买方品牌生产；具体范围仍需确认。
- **ODM**：通常指供应商提供设计方案并生产；不要假定包含知识产权转让。
- **开模 / 模具费**：用于新结构或专属零件；确认模具归属、寿命与返还条件。
- **打样费 / 打样周期 / 大货周期**：分别询问，避免把样品交期当成量产交期。
- **白牌 / 中性包装**：无品牌或不展示品牌；确认产品、说明书与外箱三处。

## 示例

### “想找软乎乎、不掉毛的沙发毯”

- 主行业词候选：法兰绒毯、珊瑚绒毯、兔毛绒盖毯（材质需确认）
- 宽搜：`沙发盖毯 法兰绒`
- 精搜：`加厚 法兰绒毯 不易掉毛`
- 找厂：`法兰绒盖毯 定制厂家`
- 待确认：尺寸、克重、单层/双层、锁边方式、是否需要印花或 logo

### “透明、硬一点、装小首饰的小盒子”

- 主行业词候选：透明 PP 收纳盒、透明 PS 包装盒、亚克力首饰盒
- 搜索：`透明 PP 首饰收纳盒`、`PS 透明包装盒`、`亚克力 首饰展示盒`
- 待确认：是运输包装还是长期展示、开合结构、尺寸、是否食品/皮肤接触、是否定制内托

### “瑜伽裤”从买家词变成工厂词

- 基础找货：`高腰 瑜伽裤 女`
- 生产路径：`锦纶 氨纶 裸感 瑜伽裤`、`无缝针织 高腰 瑜伽裤`
- 库存路径：`锦氨 瑜伽裤 库存尾货`
- 找厂路径：`无缝运动裤 加工厂`、`瑜伽服 OEM 工厂`
- 待确认：成分比例、克重、织法、是否双面磨毛、裆部结构、尺码段和首单数量

### 简短询盘模板

```text
你好，想采购【品类】，用途是【用途】，预计首单【数量】。
需要【材质/尺寸/工艺】。请问有现货或接近款吗？
麻烦提供材质与关键规格、数量阶梯价、MOQ、样品费、交期，以及报价是否含税/包装/运费。若需定制 logo，也请告知可用工艺和起订量，谢谢。
```

## 质量校验

输出前检查：

- 搜索式是否包含可识别的核心品类，而非只有风格词？
- 是否把未经证实的材质或工艺写成了事实？
- 是否至少有一个宽搜词和一个精搜词？
- 多义商品是否给出候选路径和区分问题？
- 定制场景是否询问 MOQ、样品、周期和费用？
- 是否避免使用品牌仿款、侵权或绕过平台规则的话术？
- 是否把“搜索标签”误写成“工厂证明”？
- 是否出现用户未提供的精确克重、尺寸、型号、等级或材料声明？若有，降级为候选并明确待确认。
- 是否避免无来源的降价比例、品质保证或“彻底过滤中间商”等承诺？
- 产业带词是否标记为候选，并避免把地区直接等同于质量或工厂身份？
- 替代场景是否检查食品接触、儿童、承重、电器等安全差异？

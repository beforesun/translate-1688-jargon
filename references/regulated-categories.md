# 建材、汽配与食品等高约束类目

本文件中的词用于搜索和询盘，不构成工程、车辆安全、食品安全或法律合规结论。涉及强制标准、许可、认证、承重、防火、车型适配和食品经营要求时，查询当前官方规则并由具备资质的专业人员确认。

## 建材与家装

### 拆词维度

- 材料：不锈钢、铝合金、塑钢、玻璃、PVC、PET、多层板、PPR、UPVC 等
- 工艺：钢化、夹胶、折弯、喷涂、热转印、包覆、挤出、焊接
- 参数：玻璃厚度、型材壁厚、板厚、尺寸、公差、表面处理、安装方式
- 性能/合规：承重、防火、防滑、防水、耐候、盐雾、环保释放等必须对应适用标准和检测资料

### 去营销词后的搜索分支

| 零售表达 | 本品类工程搜索方向 | 必须核对 |

“实验室工作台、流水线操作台、车间挂板”通常与家用家具在尺度、外观、边角、安全和安装上差异显著，不作为直接平替，只能借用结构词探索。

### 产业带候选

- 瓷砖/建筑陶瓷：佛山
- 淋浴房及相关五金：中山等候选产业区
- 卫浴陶瓷：潮州古巷等候选产业区
- 生态木/装饰板：临沂等候选产业区
- 门窗型材：佛山、临朐等候选产业区

产业分布会变化；用当前平台商家分布、企业资料和项目案例复核。

## 汽配与车载用品

### 拆词维度

- 材料：PVC、TPR、EVA、ABS、牛津布、海绵及其密度/硬度
- 工艺：注塑、热压、吸塑、车缝、复合、植绒
- 参数：车型/年款、左右舵、卡扣点位、接口、孔位、尺寸、耐磨、防滑、阻燃、气味

### 搜索规则

- 优先公式：`车型 + 年款 + 部位 + 材料/结构 + 配件`
- 用户未提供车型与年款时，先追问；不要用“货车/客车配件”冒充私家车通用平替。
- “车载收纳盒 → 工业周转盒”“汽车坐垫 → 货车座垫”等只能作为结构探索，不能默认孔位、气囊兼容和驾驶安全适配。
- 不推荐可能遮挡安全气囊、踏板、视线、操控件或影响座椅约束系统的改装。

### 产业带候选

汽车座垫/脚垫可尝试台州、河北清河等产业词，但必须结合车型适配和供应商当前主营验证。

## 食品与食品原料

食品没有“工业平替”逻辑。只允许在同一食品类别内切换包装、供货形态或生产服务，例如：

- 独立小包装 → 散装大包装/餐饮装（须满足实际销售与使用要求）
- 成品 → 半成品/原料（使用者必须具备相应加工、储存和经营条件）
- 品牌零售 → 合规 OEM/ODM 或自有品牌生产

### 搜索维度

- 品类/工艺：焙烤、膨化、蜜饯、果干、冷加工、速冻等
- 供货：散装大货、预包装、餐饮装、OEM/ODM、代加工
- 商务：MOQ、包装规格、保质期、储运条件、批次、交期
- 合规核验：生产主体、许可/备案、产品标签、执行标准、检测报告、过敏原、冷链和追溯信息；具体要求以当前官方规则及实际经营场景为准

### 可尝试的搜索式

- `雪花酥 散装大货 食品生产厂家`
- `芒果干 散装 原料 OEM`
- `曲奇饼干 大包装 代加工`
- `奶茶珍珠 餐饮装 供应商`
- `坚果 散装原料 食品加工`

不要搜索或推荐“零食边角料、工厂尾料、瑕疵零食、临期改标、原单食品”等高风险词。不得把散装原料直接视为可合法分装销售；先核验经营主体、场所、标签和当地现行要求。

### 产业带候选

临安坚果、潮州蜜饯、漳州饼干糕点、义乌/汕头糖果、郑州/山东诸城速冻食品可作为候选搜索地名，不代表固定唯一产地或合规保证。

## 母婴、宠物与医疗用途借词

- 婴儿隔尿垫与医用护理垫、宠物尿垫在尺寸、吸收结构、材料安全和适用标准上可能不同，不互称等价平替。
- 宠物航空箱需要通风、锁扣、结构强度和运输规则适配，工业周转箱不是默认替代品。
- 宠物围栏与工业隔离网需分别检查间隙、锐边、夹伤、倾倒和固定风险。
- “医用、食品级、婴童级”等词只有在对应证据和适用范围成立时使用，不能作为流量后缀。
